# Rebuild the web app in React with shadcn/ui

The pages become one React app with shadcn/ui, built by Vite and committed inside the Python package, so the service
still serves everything from 127.0.0.1 and an install needs no Node. Ten PRs: the design system and shell, the Ledger,
the other three day pages, the older pages, then the Jinja templates go. Main works after each one.

## Goal

- Done: every page in the React app with a sidebar, the list and a Linear-style panel; the old tasks app's bar kept on
  the day pages (the keys, one selection, saves on change, the unsaved guard, bulk by dry run, undo and redo by batch,
  the 5 s poll that holds, materials and their path checks); sign-in, the Guard and the CSP as strict as now.
- Out: features no page has today or in #203's plan; the Outbox; a command palette; pixel baselines.

### Where it lives and how it ships (DR-0705)

| Path | What |
|---|---|
| `packages/docket/web/` | the source: `src/`, `components.json`, `vite.config.ts`, the lockfile, `.nvmrc`, `openapi.json`; out of the wheel and sdist |
| `packages/docket/src/docket/web/app/` | the build, committed: `index.html`, scripts, CSS and fonts under fixed names, `licences.txt`, `routes.json`, `build.json` |

- **The service hosts the front end.** FastAPI serves the build's files under `/static/app/` and its `index.html` for
  every client route, on the same origin and port as `/api` and `/mcp` (127.0.0.1:8741). No other server, no Node at
  runtime. Vite's dev server, proxying to a throwaway service, is for development only; the Guard isn't loosened.
- A user without Node runs `uv tool install git+https://github.com/serionist/docket@<sha>#subdirectory=packages/docket`
  as today: uv_build packs `docket/web/app/` like the templates now, nothing fetched at runtime.
- Committed build, checked fresh: the web job builds again and fails on `git diff`; the quick gate checks `build.json`'s
  source hash in Python. Fixed names (served no-cache with an ETag) keep diffs small; a conflict is settled by a build.
- Licences: bundled React, Radix, shadcn/ui, Tailwind, TanStack, clsx, tailwind-merge, get-nonce (MIT), cva
  (Apache-2.0), lucide (ISC), the fonts (OFL-1.1); build and test only, axe-core (MPL-2.0) never ships. All fit.

### The API (DR-0709)

| Page | Reads | Writes, JSON | Today |
|---|---|---|---|
| shell | `GET /api/web/shell`: counts, vault, machine, index line | none | parts in `/api/status`, `/api/day` |
| Ledger, Queue, Meetings, Today | `GET /api/web/<page>`, its panel, `ledger/changed`, `ledger/text` | `ledger/write`, `ledger/save`, `ledger/open` | `views.read` (LedgerRead), `store.write`; the routes are HTML |
| Search, Recording, Briefs | `GET /api/web/search`, its panel; `recording`, `recording/audio`; `briefs` | `briefs/decision` | `/api/search`, `/api/read`, `/api/verify` lack facets and labels |
| Staging, Curate, Sync, Settings | `GET /api/web/<page>` and panels | Staging's two, Curate's four, Settings' three | HTML only |

Each read answers what its `*_view.py` builder builds today, less markup; each write calls what its form post calls,
on the writer thread, answering JSON for a 303. `devkit web-schema` writes their OpenAPI, which the quick gate checks.

### Auth and the guard

| Concern | With the app |
|---|---|
| sign-in | unchanged: `docket open`'s one-time code, `/session` sets the SameSite=Strict, HttpOnly cookie, then the page |
| a stranger | the document with the sign-in command in a meta element, 401, naming no vault or machine (DR-0704) |
| a lapsed session | `/api/web` answers 401; a dialog says run `docket open`, then Retry; typed text stays in the page |
| the Guard | unchanged: Host, Origin and Sec-Fetch-Site on writes, OPTIONS refused, no CORS (DR-0152) |
| CSRF | the Guard's checks, plus `/api/web` takes the cookie only and writes only `application/json`; no token needed |
| CSP | `script-src 'self'`, styles `'self'` plus a per-response nonce for Radix's scroll lock, no eval (DR-0706) |
| what replaces DR-0170 | a path is the document or JSON, never chosen by a header; every state a URL with today's names (DR-0704) |

### The day pages' bar (DR-0710, DR-0711)

| Behaviour | How |
|---|---|
| keys | 1 to 4, 0, e, Delete or Backspace, s, u or Ctrl+Z, x or Space, n, j and k, Enter, Esc, ?: one registry runs the command a button runs |
| selection | one; the panel follows j and k; a call moves to the row after |
| saves, guard | on change through `ledger/save`, answered with the row, title, history and version; a refused one stays unsaved, and leaving unsaved text asks (the router's blocker, `beforeunload`) |
| bulk | a dry run; skipped rows named; the old verdict rule, so no write toggles |
| undo, redo | the notice bar's Undo and Redo by batch; u presses them |
| poll | every 5 s on the op files' hash; a change refetches in place; holds while typing, ticking, a dialog or a hidden tab |
| materials | open and the text viewer through `ledger/open` and `ledger/text`, DR-0664's checks as they are |

### The screenshot loop (DR-0712)

| Rule | What |
|---|---|
| design | each page and shared component is designed with `frontend-design:frontend-design`, invoked by the Skill tool |
| run | `uv run devkit ui <page>`: seeds an invented world (empty, a working week), starts a throwaway service on port 0 with its own config, state and file token, never 8741 or the owner's folders, drives the build in Chrome |
| shots | each state (default, panel open, ticked, after a write, refused, empty) light and dark at 1440x900 and 390x844, clock, zone and motion fixed, to `.local/ui/<page>/r<n>/` |
| machine checks | axe, console and CSP errors, sideways scroll, targets of 24 px (44 coarse): block every round |
| critique | spec first (the page's table, the old app's bar), then hierarchy at a glance, density (20 rows at desktop), both themes, narrow, the words |
| rounds | 4 at most, fewer when a round finds only polish; what is left goes in the PR |

### Tests and CI (DR-0712)

| Job | Runs | Under 5 minutes by |
|---|---|---|
| Web (Linux), new | `npm ci`, lint, typecheck, Vitest, build, the build diff, the 250 KB script budget, the licences | one job, about 2 minutes, npm's cache |
| Browser (Linux, k of N) | Python Playwright in the runner's Chrome, one file per page, axe in both themes | shares split by test-weights.json (DR-0698), N grows with the pages |
| Checks, test shares | the JSON route tests in place of the render tests; the gate's web step, in Python | as now |
| Dependabot | an npm entry for `/packages/docket/web` in the weekly group, cooldown 7 days | its PR rebuilt with `npm run build`, as the models' lock is |

## Doors and data

None. The MCP tools, the vault and the ledger's op format don't change; `/api` is Docket's own until the first release
(`api.py`), and the ledger's reads answer LedgerRead, already a door (DR-0660). Page URLs keep their paths and
parameter names, so Claude's links and the tasks skill (DR-0691) open what they did. The browser stores nothing new.

## Risks

- A Windows build differs from Linux's: CI fails the diff. PR 1 builds on both and compares; output is LF.
- Every Dependabot npm PR needs a rebuild before merge. Accepted, as the models' lock.
- Pages need JavaScript now, and two looks live side by side for weeks. Accepted: a local app, the day pages first.
- Supply chain: packages run only at build time, install scripts off, exact pins a week old, the lockfile's hashes.
- #204's Jinja branch stops; its plan section carries into PR 3.
