# Reviews

Reports of reviews whose scope is the whole repo or a folder rather than one change: `review-code` with a path scope
writes them here as `YYYY-MM-DD-<slug>.md`. A change's own review is summarized in its PR, and a plan's review in the
plan's "Plan review" section.

A report records what was found at the time. Its findings become issues or plans; the report itself is not kept
current.
