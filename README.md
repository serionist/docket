# Docket

A personal memory and task manager that Claude works in. Docket keeps everything you hear, read and write (call
recordings and their transcripts, mail, chat, notes) raw and processed, in a git repo of your own, indexes it in
English and Hungarian, and runs your day from it: what you owe, what you wait for, the meetings and their prep. Claude
reaches all of it through an MCP endpoint and a Claude Code plugin, and answers with the source of every fact.

Local first: a service on your machine (Windows, macOS, Linux), your data in your own private repo, every GPU feature
optional.

**Status:** being built. Nothing to install yet.
