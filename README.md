# Docket

A personal memory and task manager that Claude works in. Your calls, mail, chats, files and the people in them, kept
in one place, searchable, and turned into tasks.

> **Docket is being rebuilt, docs first.** The design is written topic by topic in [`docs/`](docs/), then the code
> follows it. The first version is archived at [serionist/docket-v1](https://github.com/serionist/docket-v1).
